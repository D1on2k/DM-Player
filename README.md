# DM-Player
A light weight media player using Dear ImGui as a framework and win 32 API for window functions.

---

# STILL UNDER DEVELOPMENT
currently on the front end stage with a little bit of the backend in this state it would be a great skeleton for someone to use it has tab system icons and more.

---
## Features

- Clean UI
- Working Tab System
- Fully Custom Made Task Bar
- Custom Window
- Image Searching
- Working UI Scaling
- 3 / 4 Tabs finished
